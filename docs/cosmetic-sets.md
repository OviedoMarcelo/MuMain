# Cosmetic Sets

A cosmetic set changes how the armor of your character looks, without changing
its stats. While you wear one, everybody sees its helm, armor, pants, gloves and
boots instead of the ones you have equipped: you, the other players, and the
players who come into view later.

The server operator configures which sets exist. A character unlocks them as a
reward (quests, achievements, the season pass, bosses) or from a game master.

> Requires a server which offers cosmetic sets. Against another server the
> button doesn't show up.

---

## Opening it

Open the inventory (**I** or **V**) and press **Sets** in the row of buttons at
the bottom. The window opens at the left of the inventory, where the character
window would be.
**Escape** closes it.

## The list

Each row shows the armor of the set, its name and its state:

- **Worn** - you wear this set.
- **Locked** - you haven't unlocked it yet.
- **Other class** - you unlocked it, but your class can't wear it, because the
  server only allows the sets of armors your class could equip.

Click a row to pick it. **Wear** puts on the picked set; **Take off** shows your
real armor again. The worn set is remembered: you still wear it after logging
in again.

When a set has no piece for a slot (for example the sets of the Magic Gladiator
have no helm), the real item of that slot stays visible.

## Chat commands

The window uses these commands, which can also be typed:

- `/cosmetico <number>` wears the set with that number, `/cosmetico off` takes
  it off.
- `/cosmeticos` lists your unlocked sets with their numbers.

Game masters use `/darcosmetico <character> <number>` and
`/quitarcosmetico <character> <number>` to give and remove sets.
